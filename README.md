### 👨‍💻 About Me

Backend Software Engineer focused on **distributed systems**, **microservices architecture**, and **DevOps practices**, from design to production operations.

- ⚙️ I build reliable, scalable backend systems using **Java (Spring Boot)** and **C# (.NET)**.
- 🏗️ I apply **Clean Architecture**, **DDD**, and **SOLID** to write maintainable and evolutionary code.
- ☁️ On the infrastructure side, I work with **AWS**, **Azure**, **Docker**, **Kubernetes**, and **CI/CD pipelines**.
- 🚀 **Featured Project:** [Evolui CV](https://evoluicv.luanderson.dev.br/) — AI-powered resume analysis platform (Spring Boot, Next.js, LangChain4j, OpenAI).
